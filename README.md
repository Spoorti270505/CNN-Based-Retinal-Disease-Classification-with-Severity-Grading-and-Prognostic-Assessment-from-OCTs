# CNN-Based-Retinal-Disease-Classification-with-Severity-Grading-and-Prognostic-Assessment-from-OCTs
Multi-Task Learning framework for OCT-based retinal disease classification, severity grading, and prognostic assessment. Evaluates CNN backbones including DenseNet-121, achieving 97.53% accuracy and 92.76% F1-score, with POR-based biomarkers, TTA, Temperature Scaling, and Grad-CAM.
Paper link- https://ieeexplore.ieee.org/document/11651259
