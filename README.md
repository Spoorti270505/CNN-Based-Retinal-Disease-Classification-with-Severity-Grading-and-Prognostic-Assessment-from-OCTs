# CNN-Based-Retinal-Disease-Classification-with-Severity-Grading-and-Prognostic-Assessment-from-OCTs
This project presents a Multi-Task Learning (MTL) framework for automated OCT-based retinal disease analysis, performing disease classification, severity grading, and prognostic assessment. OCT scans are classified into four categories: CNV, DME, Drusen, and Normal. The framework uses a shared feature encoder to leverage cross-task learning, unlike traditional Single-Task Learning (STL). A patient-sensitive dataset of 83,484 scans was used to reduce data leakage, with ResNet-50, EfficientNet-B0, TF-EfficientNet, and DenseNet-121 evaluated. DenseNet-121 achieved the best performance with 97.53% accuracy and 92.76% F1-score. Severity and prognosis labels were generated using a morphological biomarker heuristic based on Pathological Occupancy Ratio (POR), including hypo-reflective fluid pockets and hyper-reflective extracellular deposits. Temperature Scaling, Adaptive Test-Time Augmentation (TTA), and Grad-CAM were incorporated for calibration, robustness, and interpretability.
